# 学习流程重设计 — 方案 B

> 日期：2026-03-12
> 状态：已确认

## 背景

当前 MVP 存在三个核心体验问题：
1. 翻卡和四选一让用户手动二选一，而非系统自动混合
2. 无法查看已掌握的卡片
3. 新卡没有「教学」环节，上来就考，体验单薄

参考百词斩和多邻国的学习模型，进行学习流程重设计。

## 设计目标

- 去掉用户手动选模式，系统根据掌握程度自动分配题型
- 新卡增加「展示→测试→巩固」教学三步流程
- 新增卦典页面，可浏览 64 卦掌握状态
- 所有题型客观评分，去掉翻卡自评

## 一、Session 整体流程

```
首页点击「开始学习」
  │
  ├─ 阶段一：复习到期卡（混合题型）
  │   系统根据掌握程度自动分配题型：
  │   - 掌握较差(repetitions 0-1) → 正向四选一
  │   - 掌握中等(repetitions 2-3) → 判断对错
  │   - 掌握较好(repetitions ≥ 4)  → 反向四选一
  │   全部复习完进入阶段二
  │
  ├─ 阶段二：学习新卡（教学三步）
  │   每张新卡经历：
  │   ① 展示卡 — 完整展示卦的所有信息，点击「知道了」
  │   ② 即时测试 — 紧跟一道正向四选一
  │   ③ 延迟巩固 — 3-5张后再出现，用反向四选一
  │   每5张新卡弹出软限制提醒（保留现有逻辑）
  │
  └─ 结束 → 总结页
```

首页改动：去掉模式选择器，改为「开始学习」+「卦典」两个入口。

## 二、题型规格

### 题型 1：展示卡（仅新卡教学用，不计入 SM-2）

展示该卦的全部信息：卦象符号、卦名、卦辞（点击可展开白话翻译）、上下卦。
用户点击「知道了」后进入下一步。

### 题型 2-4：正向四选一（简单难度）

| 子类型 | 题面 | 选项 | 对应卡片类型 |
|--------|------|------|-------------|
| 认名 | 卦象符号 | 4 个卦名 | A |
| 识义 | 卦名 | 4 段卦辞 | C |
| 拆卦 | 卦象符号 | 4 组上下卦 | G |

SM-2 评分：选对 quality=4，选错 quality=1。

### 题型 5：判断对错（中等难度）

随机展示一个卦象 + 一个卦名（50% 概率正确配对，50% 概率错误配对）。
同样可用于卦辞和上下卦维度。
SM-2 评分：答对 quality=4，答错 quality=1。

### 题型 6-8：反向四选一（困难难度）

| 子类型 | 题面 | 选项 | 反向的卡片类型 |
|--------|------|------|---------------|
| 名→象 | 卦名 | 4 个卦象符号 | A 反向 |
| 辞→名 | 卦辞 | 4 个卦名 | C 反向 |
| 上下卦→象 | 上下卦构成 | 4 个卦象符号 | G 反向 |

SM-2 评分：选对 quality=4，选错 quality=1。

## 三、题型分配策略

| 场景 | 题型 | SM-2 更新 |
|------|------|----------|
| 新卡·展示 | 展示卡 | 不更新 |
| 新卡·即时测试 | 正向四选一（随机子类型） | 更新 |
| 新卡·即时测试答对后延迟巩固 | 反向四选一（随机子类型） | 不更新 |
| 新卡·即时测试答错后 requeue | 正向四选一（随机子类型） | 不更新 |
| 复习·掌握较差(rep 0-1) | 正向四选一 | 更新 |
| 复习·掌握中等(rep 2-3) | 判断对错 | 更新 |
| 复习·掌握较好(rep ≥4) | 反向四选一 | 更新 |

## 四、卦典页面

### 列表视图

64 卦按卦序排列，每卦显示：卦象符号、卦名、掌握状态。

掌握状态三档：
- 未学习：该卦 3 张卡都没学过（lastReviewDate 均为空）
- 学习中：至少 1 张学过但未全部达到 repetitions ≥ 4
- 已掌握：3 张卡 repetitions 都 ≥ 4

### 详情页

展示该卦完整信息（卦象、卦名、卦辞+白话翻译、上下卦），底部显示 3 张卡各自的学习状态。纯浏览，不触发学习。

### 首页统计与卦典统计的口径区别

- 首页：卡片级 `已掌握 36/192 卡片`
- 卦典：卦级 `已掌握 8/64 卦`

## 五、数据层变化

### 卦数据新增字段

```typescript
interface Hexagram {
  // ... 现有字段不变
  judgmentTranslation: string;  // 卦辞白话翻译
}
```

### 新增题型类型

```typescript
type ExerciseType =
  | 'teaching'        // 展示卡
  | 'quiz-forward'    // 正向四选一
  | 'true-false'      // 判断对错
  | 'quiz-reverse';   // 反向四选一
```

### 题型分配逻辑

```typescript
function assignExerciseType(cardState: CardState | undefined): ExerciseType {
  if (!cardState || cardState.repetitions <= 1) return 'quiz-forward';
  if (cardState.repetitions <= 3) return 'true-false';
  return 'quiz-reverse';
}
```

## 六、边界场景处理

| 边界场景 | 处理方式 |
|---------|---------|
| 同卦多张新卡 | 展示卡按卦去重，session 内用 Set<number> 追踪已展示的卦 |
| 即时测试答错 | requeue 充当巩固（3-5 张后重现），不额外安排延迟巩固 |
| 即时测试答对 | 安排延迟巩固（3-5 张后，反向四选一，不更新 SM-2） |
| 队列末尾放不下巩固卡 | insertAt = Math.min(currentIndex + offset, queue.length) |
| repetitions 重置后的掌握判断 | 用 lastReviewDate !== '' 判断是否学过，避免误判为"未学习" |
| cardState 为 null | 防御性处理，默认分配正向四选一（最简单） |
| 判断对错的错误配对 | 从真实卦数据随机选取，排除正确答案 |
| 判断对错正确/错误比例 | Math.random() < 0.5，不严格交替，避免可预测 |
