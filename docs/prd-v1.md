# 周易记忆卡 — MVP (v1.0) 产品需求文档

## 1. 产品概述

**产品名称**：周易记忆卡（ZhouYi Memory）

**一句话描述**：用间隔重复（Spaced Repetition）帮助用户记忆周易六十四卦的基础知识。

**目标用户**：对周易感兴趣、希望系统记忆六十四卦基本信息的学习者。

**核心价值**：把枯燥的死记硬背变成科学的间隔复习，让用户在碎片时间里高效掌握六十四卦。

## 2. 技术方案

| 项目 | 选型 |
|------|------|
| 框架 | React 18 + TypeScript |
| 构建 | Vite |
| 样式 | Tailwind CSS |
| 部署 | PWA（可离线使用，可添加到主屏幕） |
| 数据存储 | 浏览器本地存储（localStorage / IndexedDB） |
| 记忆算法 | SM-2 |
| 后端 | 无（纯前端，MVP 不需要服务器） |

## 3. 内容范围

MVP 仅覆盖 **六十四卦的基础信息**：

| 字段 | 说明 | 示例 |
|------|------|------|
| 卦象 | Unicode 卦象符号 | ☰ |
| 卦名 | 卦的名称 | 乾 |
| 卦辞 | 卦的原文辞句 | 元亨利贞 |
| 上卦 | 组成该卦的上经卦 | 乾（天） |
| 下卦 | 组成该卦的下经卦 | 乾（天） |

> MVP **不包含**：爻辞、彖传、象传、序卦传等扩展内容。

## 4. 卡片类型

MVP 包含 3 种卡片类型：

### 类型 A：卦象 → 卦名

- **正面**：显示卦象符号（如 ☰）
- **背面**：卦名（如「乾」）
- **考察能力**：看到卦象能说出卦名

### 类型 C：卦名 → 卦辞

- **正面**：卦名（如「乾」）
- **背面**：卦辞（如「元亨利贞」）
- **考察能力**：看到卦名能回忆卦辞

### 类型 G：卦象 → 上下卦构成

- **正面**：六爻卦象符号（如 ䷀）
- **背面**：上卦 + 下卦（如「上乾下乾」）
- **考察能力**：看到复合卦象能分解出上下经卦

> 每卦最多生成 3 张卡片，64 卦共 **最多 192 张卡片**。

## 5. 学习模式

### 5.1 翻卡片模式（Flip Card）

1. 显示卡片正面
2. 用户心中回忆答案
3. 点击「翻转」查看背面
4. 用户自评：
   - **完全不会**（Again） → quality = 0
   - **模糊**（Hard） → quality = 2
   - **想起来了**（Good） → quality = 4
   - **很简单**（Easy） → quality = 5

### 5.2 四选一模式（Quiz）

1. 显示卡片正面
2. 给出 4 个选项（1 个正确 + 3 个干扰项）
3. 用户选择答案
4. 显示正确/错误反馈
5. 自动评分：
   - 选错 → quality = 0
   - 选对 → quality = 4

> 两种模式用户可随时切换，不影响学习进度。

## 6. 学习流程

### 核心原则：打开就学，随时可停

```
用户打开 App
  → 有到期复习卡？→ 出复习卡
  → 复习卡做完 / 没有复习卡？→ 出新卡片
  → 用户随时可停，下次继续
```

### 详细流程

1. **进入首页**：显示简洁的学习入口 + 当前学习统计概览
2. **点击「开始学习」**：进入学习 session
3. **出卡逻辑**（优先级从高到低）：
   - 已学过且到期需复习的卡片（按到期时间排序）
   - 未学过的新卡片（按卦序排列）
4. **单张卡片流程**：展示 → 作答 → 反馈 → SM-2 更新 → 下一张
5. **结束 session**：
   - 用户主动点「结束」退出
   - 或当前无更多到期卡片且用户不想学新卡
6. **Session 结束页**：展示本次学习统计（复习了几张、学了几张新的、正确率）

### 不做的事

- ~~每日目标设定~~
- ~~打卡/连续天数~~
- ~~强制学习数量~~

## 7. SM-2 算法规格

每张卡片维护以下状态：

```typescript
interface CardState {
  cardId: string;          // 卡片唯一标识
  easeFactor: number;      // 难度因子，初始 2.5
  interval: number;        // 当前间隔（天）
  repetitions: number;     // 连续正确次数
  dueDate: string;         // 下次复习日期 (ISO 8601)
  lastReviewDate: string;  // 上次复习日期 (ISO 8601)
}
```

### 算法逻辑

```
输入: quality (0-5)

if quality < 3:
  repetitions = 0
  interval = 1
else:
  if repetitions == 0: interval = 1
  elif repetitions == 1: interval = 6
  else: interval = round(interval * easeFactor)
  repetitions += 1

easeFactor = max(1.3, easeFactor + (0.1 - (5 - quality) * (0.08 + (5 - quality) * 0.02)))
dueDate = today + interval 天
```

## 8. 数据模型

### 8.1 卦数据（静态，内置于代码中）

```typescript
interface Hexagram {
  id: number;              // 1-64，按卦序
  name: string;            // 卦名，如「乾」
  symbol: string;          // 六爻卦象 Unicode，如「䷀」
  trigram: string;         // 八卦卦象（仅八经卦），如「☰」
  judgment: string;        // 卦辞
  upperTrigram: string;    // 上卦名称
  lowerTrigram: string;    // 下卦名称
}
```

### 8.2 学习记录（动态，存储在本地）

```typescript
interface StudyRecord {
  cardStates: Record<string, CardState>;  // cardId → 卡片状态
  totalReviews: number;                    // 累计复习次数
  lastStudyDate: string;                   // 上次学习日期
}
```

### 存储方案

- 优先使用 `localStorage`（简单、同步、够用）
- 如果数据量增长超出限制，迁移到 `IndexedDB`
- MVP 不做云同步、不做导入导出

## 9. 页面结构

MVP 只需 **3 个页面**：

### 9.1 首页（Home）

- 学习入口按钮「开始学习」
- 统计概览：已学卡片数 / 总数、今日待复习数
- 模式切换（翻卡片 / 四选一）

### 9.2 学习页（Study）

- 卡片展示区域
- 翻卡片模式：翻转动画 + 自评按钮
- 四选一模式：选项按钮 + 正确/错误反馈
- 顶部进度条（本次 session）
- 「结束学习」按钮

### 9.3 学习完成页（Summary）

- 本次学习统计
  - 复习卡片数
  - 新学卡片数
  - 正确率（四选一模式）
- 「返回首页」按钮

## 10. 非功能需求

| 项目 | 要求 |
|------|------|
| 离线可用 | PWA Service Worker 缓存，断网可正常使用 |
| 响应式 | 移动端优先，同时适配桌面端 |
| 性能 | 首屏加载 < 2s，卡片翻转无卡顿 |
| 数据安全 | 本地存储，提醒用户清除浏览器数据会丢失进度 |
| 浏览器支持 | Chrome / Safari / Firefox 最近 2 个主版本 |

## 11. MVP 不做的功能

以下功能明确排除在 MVP 之外，留待后续版本：

- 用户账号 / 云同步
- 每日目标 / 打卡系统
- 爻辞、彖传、象传等扩展内容
- 卡片类型 B / D / E / F（见路线图）
- 自定义卡片
- 学习数据导入导出
- 深色模式
- 多语言支持
- 社交 / 排行榜功能
