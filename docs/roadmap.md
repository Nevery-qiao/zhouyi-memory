## v1.0 — MVP：基础卦象记忆

> 目标：跑通核心学习循环，验证产品价值

### 功能清单

- [x] 64 卦基础数据（卦象、卦名、卦辞、上下卦）
- [x] 3 种卡片类型
  - A：卦象 → 卦名
  - C：卦名 → 卦辞
  - G：卦象 → 上下卦构成
- [x] 翻卡片模式（自评打分）
- [x] 四选一选择题模式
- [x] SM-2 间隔重复算法
- [x] 自动出卡（复习优先 → 新卡补充）
- [x] 本地数据持久化
- [x] PWA 离线支持
- [x] 移动端适配

---

## v1.1 — 内容扩展：更多卡片类型

> 目标：覆盖更多记忆维度，加深对卦的理解

### 新增卡片类型

| 类型 | 正面 | 背面 | 考察能力 |
|------|------|------|----------|
| B | 卦名 | 卦象 | 看到名字能画出卦象 |
| D | 卦辞 | 卦名 | 看到卦辞能反推卦名 |
| E | 上下卦构成 | 卦名 | 知道组合能说出卦名 |
| F | 卦名 | 上下卦构成 | 知道卦名能说出组合 |

### 其他功能

- [ ] 用户可选择启用/禁用特定卡片类型
- [ ] 卡片类型难度统计（哪类卡最容易错）
- [ ] 学习设置页（可调整新卡数量上限等）

---

## v1.2 — 体验优化：学习数据可视化

> 目标：让用户看到自己的进步，提升学习动力

- [ ] 每卦掌握详情页（各卡片类型的记忆状态）

- [ ] 深色模式

## v2.0 — 深度内容：爻辞与传文

> 目标：从「认识卦」升级为「理解卦」

### 内容扩展

- [ ] 384 爻辞（每卦 6 爻）
- [ ] 新卡片类型：爻位 → 爻辞
- [ ] 新卡片类型：爻辞 → 所属卦/爻位
- [ ] 彖传、象传内容（可选学习模块）

### 学习能力增强

- [ ] 按主题/分类学习（如：只学八经卦、只学某一宫的卦）
- [ ] 自定义学习 session（用户选择学哪些卡）
- [ ] 难点专练模式（集中复习反复出错的卡片）

## 未来构想（不承诺时间线）

以下是可能探索的方向，视用户反馈决定优先级：

- **社区功能**：排行榜、学习小组
- **AI 辅助**：根据卦象生成助记故事
- **占卜练习**：模拟起卦 + 解卦练习
- **关联学习**：卦与卦之间的关系（综卦、错卦、互卦）
- **多语言**：英文版本
- **桌面端**：Electron 或 Tauri 打包
